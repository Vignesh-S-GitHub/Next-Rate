## Recreate

Run `npm ci`, `npx playwright install chromium`, then `node scripts/capture_screenshots.cjs`. Use `npm run test:browser` to check every screen without replacing images. Optional `CHROMIUM_EXECUTABLE_PATH` selects an installed Chromium.
